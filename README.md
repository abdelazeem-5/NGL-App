## 📖 About The Project

**NGL App** is a backend API that powers an anonymous messaging platform — like the popular "NGL" app. Users can receive **anonymous messages** through a shareable link, while the backend handles everything securely: authentication, email verification, password resets, and message delivery.

The project is built with a clean **layered architecture** for separation of concerns and maintainability.

```text
Route → Controller → Service → Repository → Database
